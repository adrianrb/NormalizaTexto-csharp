# Release 1.1.3

Standalone executable for **NormalizaTexto**.

## What's Changed
- Embedded the `SyncTextBox` control into the application.
- `NormalizaTexto.exe` no longer requires `LibComponentesCustomizados.dll`.
- Removed the external project reference from the solution and project file.
- Scroll synchronization between both panes remains fully functional.

## Requirements
- Windows with .NET Framework 4.8.
